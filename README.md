# 電商比賽刷題 APP｜章節版（免會員）

**學生入口**：https://istevenyu-debug.github.io/ecommerce-competition-quiz/

本版於 2026-10-15 更新，無需會員或 Firebase；使用 GitHub Pages 靜態網站。網站每次載入 `questions.json`（500 題）與 `chapter-groups.json`（14 章、25 組）。

## 使用方式

1. 首頁選擇「國貿大會考」、「電子商務與跨境電商」或「兩者綜合模擬」。
2. 國貿／電商模式：先選章節，再選第 1 回、第 2 回等固定題組。
3. 每回最多 30 題，原章不足 30 題按實際題數出題，**同一卷絕不重複題目**，也不混用其他章題目。重練同一組會改變題序，保留每題的練習次數。
4. 同一章提供「本章錯題練習」；每回亦提供「本回錯題」。一次錯題練習最多 30 題，若不足則依實際錯題數；答對會自待複習清單移除。
5. 「兩者綜合模擬」每回 30 題（國貿 15 題＋電商 15 題），各題庫優先選未刷題。可選擇是否包含需要外部附表的信用狀案例題。
6. 交卷顯示答對數與百分制成績，並可逐題檢討。首頁「近 10 次練習成績」保留新舊版正式成績，包含章節／題組名稱及正確題數。
7. 未交卷的答案與位置自動暫存，同一瀏覽器可繼續作答。

所有使用者進度、錯題、未交卷及最近 10 次成績僅存在**該瀏覽器 localStorage**，沿用舊版 `ecommerce-quiz-local-v1` 鍵，不會清除既有資料；不同裝置不共用，清除瀏覽器資料將失去紀錄。

## 題庫與題組

- **國貿大會考**：400 題、11 章、20 個題組（原始第一章「經貿資訊」未收於彙編）。
- **電子商務與跨境電商**：100 題、3 章、5 個題組。
- `questions.json` 包含原題識別碼、題幹、四選項、標準答案、章節與題組資訊。已補齊先前漏轉的 8 題。
- `chapter-groups.json` 是題組權威定義，每回的 `questionIds` 只包含本章題目，並驗證完整覆蓋且無重複。
- 國貿第十二章 50 題分為五個獨立信用狀案例，每組10題；**網站尚未附上 PDF 的完整單據附件**，請對照原始《國際貿易大會考題庫》第 58–80 頁作答。題目視圖會標明該案例的附件頁碼。
- 現已新增 `explanations.json`：500 題學生版解析，逐題含核心觀念、四選項解說、必記重點。交卷後在「逐題檢討」按「查看詳解」展開閱讀；教師審核稿的紅色「待複核」提醒不放進學生畫面。
- 公開 GitHub Pages 的題目及答案可供訪客檢視，僅供教學與練習使用。

## 信用狀案例一 10 題專用入口
國貿第十二章依原題庫保留五個案例，每個案例各10題，取消舊版30題／20題組法。案例一原 PDF 第 56–57 頁出題，第 58–60 頁為信用狀、匯票、發票與提單。網站 `lc-case1.json` 保留附件原文及空格，每題預設顯示相關欄位，可向下滑動選答並展開全文文字欄位。原紙本單據空格位置仍請以 PDF 為準。如果本題涉及 Shipping Order（S/O）、提單（B/L）或提單欄位，會將 46A 欄位中要求的完整海運提單英文條款優先顯示在本題參考文字最上方，以便直接上下滑動對照；答案與教師審核提醒仍不會出現在作答頁。案例二至五未修改。

## 信用狀案例一～五：依題型選文字或原始圖像

50 題（5 × 10 題）依原始 PDF 第 56～80 頁逐題設定參考資料：一般信用狀規範題只列原英文信用狀欄位；遇到單據空格、位置或版面題才提供從原始 PDF 裁切的完整匯票、商業發票、包裝單或提單圖。12 張圖保留原始表格與空格、不預填標準答案。部分題目預設顯示圖片，其他題目在「查看原始單據圖」中選看。點選圖片進入深色檢視視窗，支援手機雙指縮放與拖曳、桌面滾輪與縮放按鈕。

涉及 Shipping Order 或 Bill of Lading 的題目，完整顯示原始信用狀 46A 海運提單條款。每個案例另有 10 題專練入口，保留既有題組與 500 題題數、學生 localStorage 成績。新的 `lc-all-cases.json` 只含原始附件內容與每題參考資料對應，沒有正解與教師紅色提醒；原始單據圖在 `assets/lc/`。

## 手機測驗畫面（2026-10-16）

手機進入「實際作答」頁時，隱藏 APP 網站標題、模式說明、版本等頁首資訊，答題區從畫面頂部開始並放大題目、選項。返回首頁、章節列表、成績與檢討頁時，恢復頁首；電腦版保留頁首。

作答後會自動跳下一題，程式先取消上一題點擊選項的焦點；手機的 hover 停留色也會被重設，所以**未作答的新題四個選項恢復同樣淡色**。返回已作答題目時，仍可看到該題原本選項並修改。

國貿章節列表會顯示「第一章　經貿資訊」作為**無題目、不可點擊**的說明卡。依據原始 PDF，這章是考試範圍，但原題庫彙編沒有收錄本章歷屆題目，500 題分組及評分資料均不變。

## L/C 四個選項都有原始佐證

第十二章五個案例共50題，每題四個選項 A、B、C、D 分別對應原信用狀條款、原附件的實際欄位，或可展開的中立審單規則。共建立200個選項來源指向。作答畫面不顯示各選項正誤、教師審核提醒，原題庫有歧義的答案仍保留教師確認。

## 三種柔和底色

- 國貿大會考：淡藍色
- 電子商務與跨境電商：淡綠色
- 兩者綜合模擬：淡紫色

顏色套用首頁三個分類卡及各自章節、出卷、答題、檢討頁；內容仍使用深色文字，保持對比與可讀性。

## 站點發布

GitHub Repository → Settings → Pages → **Build and deployment Source: GitHub Actions**。
每次 main 有新提交即會觸發 `.github/workflows/pages.yml`，先檢查程式和題庫分組，再發布 `index.html`、`app.js`、`questions.json`、`chapter-groups.json`、`explanations.json`、`lc-case1.json`、`lc-all-cases.json` 與 `assets/lc/` 原始圖片。

執行 `node test/check-bank.cjs` 可檢查全部 500 題與 25 個題組的分配。
